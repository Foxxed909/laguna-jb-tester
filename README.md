# Laguna XS 2.1 Jailbreak Tester

Simple browser-based chat for `poolside/laguna-xs-2.1:free` on OpenRouter.

**Grok is King.**

## How to use

1. Open `index.html` locally or deploy to Vercel
2. Paste your OpenRouter API key
3. The Spirit system prompt is already loaded
4. Type `hi` and send

## Model

- `poolside/laguna-xs-2.1:free`
- `poolside/laguna-xs-2.1`

## Notes

Key stays in your browser only. Nothing is stored.
